1. Special-character pass. Scans for C++, C#, .NET Core, Node.js first, longest match first, and blanks each hit. Stripping punctuation first would turn C++ into c and report the wrong skill.

2. N-gram pass. Slides 1-, 2- and 3-word windows over what remains, taking the longest match at each position. That is what stops Spring Boot also matching bare Spring.

3. Set comparison. Both your skills and the advert's go through the same dictionary, then: matched = ∩, missing = required − yours, extra = yours − required.
